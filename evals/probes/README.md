# 记忆与恢复探针（阶段二占位）

本目录为评测体系**阶段二（质量度量）**预留，当前**不包含任何实现代码**。

阶段二将在此落地：

- **M8 记忆可靠性探针**（FAMA 类）：用户偏好变更后能否弃用过时记忆，长对话中关键情感事件是否可召回；
- **M7 打断恢复探针**：工具调用间 `interrupt()` 后恢复，断言已完成的工具不重放、无重复副作用；
- 跨会话人格一致性探针。

阶段一约束：

- 只测确定性的东西与关键词粗筛的语义结果；探针不引入外部平台依赖；
- 用例数据放在 `evals/cases/`，执行器放在 `evals/runners/`，本目录只放探针实现（阶段二）；
- `category` 使用字符串（如 `resume` / `memory_reliability`），不要写死成枚举，保证报告字段可容纳新指标类型。

指标编号与评测体系三阶段路线的对照见 [`../README.md`](../README.md)。
