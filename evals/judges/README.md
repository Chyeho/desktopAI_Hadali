# LLM-as-Judge 评分器（阶段二占位）

本目录为评测体系**阶段二（质量度量）**预留，当前**不包含任何实现代码**。

阶段二将在此落地：

- 人格一致性 / 人格漂移率评分 rubric（5 分制）
- 工具失败回复自然度评分（M4 从关键词粗筛升级为 LLM-as-Judge）
- 工具-陪伴切换自然度评分

阶段一约束：

- 只测「确定性的东西」和「可用关键词粗筛的语义结果」，不引入 LLM-as-Judge；
- 不依赖外部平台（langsmith / deepeval / ragas），只用 pytest + 现有项目依赖；
- 新增用例放在 `evals/cases/`，测试入口放在 `evals/test_*.py`，本目录只放评分器实现（阶段二）。

如需登记新的 rubric 名称或指标编号，先在本文件补充条目，实现留到阶段二。
